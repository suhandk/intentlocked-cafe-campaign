# Simple café website demo

Open `index.html` directly in a browser, or visit `/cafe-demo/index.html` while the project frontend is running.

This standalone page uses basic HTML, inline CSS and a small original inline SVG logo. It has no JavaScript, animation, external fonts, tracking, packages or API requirements. Navigation links jump to the menu, about and location sections. The optional map link opens a city search on Google Maps.

Namma Café, the menu, prices and opening hours are explicitly illustrative. No exact street address or phone number was supplied, so the page does not invent those details. Replace demo values with owner-approved information before using this as an actual café site. The page is a hand-authored example of website output, not evidence of a live AI generation or Guardian approval.

The project’s campaign flow and website generator are not modified by this static example.
